# SumPal Docs

Public website for the SumPal (셈벗) iPad app. This repository only holds the GitHub Pages files used by App Store Connect and the in-app Info screen. The app source lives in a separate private repository.

## Pages

- Marketing URL: `https://fakukulab.github.io/SumPalDocs/`
- Support URL: `https://fakukulab.github.io/SumPalDocs/support/`
- Privacy Policy URL: `https://fakukulab.github.io/SumPalDocs/privacy-policy/`
- Version info: `https://fakukulab.github.io/SumPalDocs/version/`

## Files

- `index.md` – landing page
- `privacy-policy.md` – privacy policy
- `support.md` – support and FAQ
- `version.md` – release notes (update this when the app version changes)
- `_config.yml` – Jekyll (`minima` theme) settings

## Publishing

GitHub Pages is served from the `main` branch, root folder. Changes pushed to `main` go live automatically.
